# Inverse Hunter 🐭→🦅

食物連鎖を逆走する、生存と革命の3Dアクションゲーム。

> "You were prey. Now you are everything. But everything has something to lose."

Three.js (WebGL) で作られた、ブラウザ単体で動く3Dアクションゲームです。
**`index.html` 1ファイルだけ**で完結します。ダブルクリックで開くだけでプレイできます。

## 特徴

- **変身チェーン**: ネズミ → キツネ → ヘビ → ワシ → オオカミ と進化し、それぞれ移動・戦闘・知覚が変化
- **エイム可能な攻撃**: マウス / タッチで照準を合わせて攻撃する3Dアクション
- **本能ゲージ**: 形態らしい行動でゲージが回復、変身に消費
- **形態別センスモード**: ネズミの超音波、ヘビの熱源、ワシの俯瞰など見え方が変わる
- **PC / スマホ横画面 対応**: WASD/矢印キー + マウス、またはバーチャルスティック + タッチエイム

## 操作方法

### PC
| 操作 | キー |
|------|------|
| 移動 | `WASD` または `矢印キー` |
| 視点 | マウス移動 / 右ドラッグ |
| 攻撃（エイム） | 左クリック |
| ダッシュ / ジャンプ | `Space` |
| しゃがむ・潜る | `Shift` |
| 変身ホイール | `Q` / マウスホイール / `1`〜`5` |
| センスモード | `E` |

### スマホ（横画面）
- 左側バーチャルスティック: 移動
- 右側ドラッグ: 視点 & 攻撃エイム（離すと攻撃）
- 画面下のボタン: 変身 / ジャンプ / センス

## ファイル構成

- **`index.html`** … 配布用の**単一統合ファイル**。これ1つだけで動きます（Three.js のみ CDN 読み込み）。ダブルクリックで開けばプレイ可能。
- `game.js` … 開発用ソース（編集しやすいよう分離してあります）。
- `build.py` … `game.js` を `index.html` にインライン化して単一ファイルを再生成するスクリプト。

## 開発

```bash
# ローカルサーバーで確認
python3 -m http.server 8080      # → http://localhost:8080

# game.js を編集したら単一ファイルを再生成
python3 build.py
```

> `index.html` だけ欲しい場合は `index.html` を1ファイル渡すだけでOKです。
